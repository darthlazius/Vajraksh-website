# VAJRAKSH SENTINEL

Static portfolio website derived from the supplied product dossier.

## Deploy to Vercel

Import this folder as a new Vercel project. Leave the framework preset as **Other** and the build command blank. Vercel will serve `index.html`, `styles.css`, and `script.js` directly.

The site has no API routes, database, form submission service, or environment variables. The briefing form confirms interaction on the page only; connect it to the company's preferred contact service when one is selected.

## Local preview

Open `index.html` in a browser, or serve this directory with any static file server.
